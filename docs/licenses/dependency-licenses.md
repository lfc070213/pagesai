## 13. 已知限制

- 只读、离线：不访问网络、不安装依赖、不读取任何 `.env`、凭据、数据库、Maildir 或用户数据。
- `Cargo.lock` 不含许可字段；离线时无法从 crates.io 元数据确认，因此 crate 一律标“待确认”。
- npm 的许可来自锁文件声明，可能与实际包内 `LICENSE` 不一致；发布前仍需在独立构建区复核。
- 素材识别只依赖文件内可见的 SPDX/@license/版权行；未发现标记时保持“待确认”，不推断。
- 本清单不是法律意见，也不替代 `THIRD_PARTY_NOTICES.md` 的分发义务。
