# 安全说明

本文说明 PagesAI 公开版**已实现**的安全控制、**尚未实现**的部分，以及部署者必须承担的责任。它不是安全认证，而是边界清单。

## 1. 范围与威胁模型

| 角色/组件 | 信任假设 |
| --- | --- |
| 部署者 | 可信；负责主机、TLS、备份、密钥、适配器代码 |
| 注册用户 | 不可信；只能访问自己的资源 |
| 管理员 | 可信但非全权；只有 `admin` 一种角色 |
| 模块代码 | 由部署者登记；未启用时不得进入进程 |
| 部署注入的适配器 | **等同可信代码**（在进程内执行），必须来自受控来源 |
| 外部服务（模型、SMTP/IMAP） | 不可信网络；凭据必须受保护 |
| 用户生成的站点/邮件 HTML | 不可信；必须净化或隔离 |
| `dev.js` 开发入口 | **仅本地**；其身份头是开发桩，绝不是认证 |

主要风险：越权访问、会话劫持、管理员被抢占、路径越界、未安装模块的隐藏接口、HTML/脚本注入、密钥泄露、适配器被替换、上传体积耗尽资源。

## 2. 已实现（公共核心）

| 控制 | 实现位置 | 说明 |
| --- | --- | --- |
| 零第三方依赖 | `core/`、`modules/` | 只用 Node 内置模块 |
| 口令哈希 | `core/identity/passwords.js` | `scrypt`（N=16384, r=8, p=1），`timingSafeEqual` |
| 口令/用户名策略 | `core/identity/service.js` | 口令 8–200；用户名 3–32、保留名拒绝、大小写不敏感唯一 |
| 会话令牌 | `core/identity/store.js` | 32 字节随机；只存 SHA-256 摘要；Cookie `HttpOnly; SameSite=Lax` |
| 会话撤销 | `core/identity/service.js` | `authVersion` 递增，旧令牌立即失效 |
| 单层管理员 | 同上 | 一次性引导；最后管理员保护；无第二层角色 |
| 引导令牌 | `core/config` + `core/server.js` | 设置 `PAGESAI_BOOTSTRAP_TOKEN` 后必须匹配 |
| 邮箱验证 | 同上 | 验证码 10 分钟、5 次尝试、10 分钟 5 次发送；不允许跳过 |
| 错误信息 | `core/errors.js` | 稳定错误码 + 固定文案；登录不区分账号是否存在 |
| 请求体上限 | `core/server.js` | 64 KiB（超限 413） |
| 未安装即无路由 | `core/registry/host.js` | 未登记不 `require`，未启用不挂路由 |
| 路径越界拒绝 | `core/storage/registry.js` | 绝对路径、反斜杠、空字节、`.`/`..`、越界 |
| 区域授权 | 同上 | 模块归属、允许操作、按用户所有权、Disk 只读 |
| 隐式换根拒绝 | 同上 | 物理根变化必须显式确认 |
| 持久化保护 | `core/storage/*` | 原子替换写、`0600`、格式校验、损坏拒绝启动 |

## 3. 已实现（业务模块）

| 模块 | 控制 |
| --- | --- |
| 全部模块 | 未认证写 403、读 401；跨用户 403；不泄露归属；不暴露宿主路径；零第三方依赖 |
| Pages | 正式路径使用 Mongo + ContentStore；站点、任务、材料与产物按 `ownerId` 隔离；站点写入用 revision CAS 防覆盖；任务状态条件迁移，终态不被迟到结果覆盖；公开/预览不依赖管理会话并使用 sandbox CSP；文件路径拒绝 `..`/绝对路径/盘符/反斜杠/编码绕过；模型只保存 `env:` 密钥引用；worker 有独立子进程、超时和内存上限；AI 结果只写工作修订，发布才公开；租户后端只绑定回环预分配端口，代理剥离管理凭据并丢弃 `Set-Cookie`，默认不下发主库数据库凭据 |
| Disk | 稳定 `fileId` + 修订；`baseRevision` 冲突不覆盖；`operationId` 幂等；软删/恢复；分享令牌有 TTL、可撤销（撤销后 410）；配额按用户逻辑字节（含软删）；区域白名单；未实现适配器返回 409 |
| Glim | 身份只来自 `ctx.user`，无固定 owner 回落；connector 必须显式登记，不扫描局域网；`trustedConnectorOrigins` 精确匹配；登记 ≠ 授权，grant/revoke 实时生效；工具只返回已授权且 `implemented=true`；endpoint 必须是绝对 http/https 且不得内嵌凭据 |
| Mail | 系统 `from` 固定，用户不可伪造；用户发信单独开关；验证码哈希存储、限流、不泄露收件人是否存在；幂等键去重；HTML 白名单净化（含编码绕过、SVG、事件属性）；附件下载先校验所有权；危险类型降级为 `application/octet-stream`；`deliveryStatus` 不虚报 |
| Survey | 所有者/管理员校验；发布快照不可变；关闭后拒填；匿名填写是显式例外；附件按目录隔离、越权 403；CSV 转义；未配置 `dataFile` 含文件题时 409 |
| Paper | 所有权检查；原件路径只由服务端生成、删除时校验不越出 `uploadsDir`；上传大小/Base64/文件名/语言/`topK` 校验；无文本层 422 不落库；问答引用只保留真实 sid；检索不可用明确降级，不伪造来源 |

## 4. 尚未实现（重要）

| 缺口 | 风险 | 现状 |
| --- | --- | --- |
| TLS/HTTPS | 明文传输凭据与会话 | 核心不终结 TLS；必须由反代承担 |
| 登录限流 | 口令爆破 | 只有验证码有限流，登录接口**没有**限流 |
| CSRF 令牌 | 跨站请求伪造 | 仅 `SameSite=Lax`；无 CSRF token |
| 安全响应头 | 点击劫持、MIME 嗅探 | Pages 控制台与公开/预览已有 CSP 和 nosniff；全站 HSTS/X-Frame-Options 仍需反代统一配置 |
| 审计日志 | 无法追溯高风险操作 | 模块只记录局部状态，无统一审计 |
| 秘密静态加密 | 备份/磁盘泄露 | `config.secrets` 和模型 `keyRef` 只是引用，无加密存储实现 |
| 符号链接 `realpath` | 词法校验可能被绕过 | 核心 `resolvePath` 只做词法校验 |
| 执行沙盒 | AI/工具代码逃逸 | Pages 仅有子进程、资源限制与最小环境；没有容器安全沙盒，不能抵御恶意代码 |
| 客户端签名/更新校验 | 安装包被替换 | 客户端与同步引擎已实现；本机缺签名/公证材料，更新端点与公钥仍为占位 |
| 适配器供应链 | 注入的适配器可执行任意代码 | 由部署者负责来源与审查 |
| `dev.js` 暴露 | 开发身份头被当成认证 | 必须只在 `127.0.0.1` 本地使用 |
| 公开页面源级隔离 | 用户 HTML/脚本与控制面可能共享 URL 源 | 当前以 sandbox CSP、禁 connect/form 和无会话读取降低风险；高保证部署仍应使用独立公开源/域名 |
| 漏洞披露流程 | 无法安全接收报告 | `SECURITY.md` 已写政策；接收报告的渠道仍为占位 |
| 许可证 | 法律风险 | 根 `LICENSE` 未确定（K7） |

## 5. 部署加固清单

1. 只监听 `127.0.0.1`，由反向代理对外提供 TLS；禁止把核心或模块 `dev.js` 直接暴露公网。
2. 反代补齐：HSTS、CSP、`X-Content-Type-Options`、`X-Frame-Options`、请求体限制、登录接口限流。
3. 设置强随机 `PAGESAI_BOOTSTRAP_TOKEN`；引导完成后清除。
4. 秘密放权限受限文件或密钥管理（示例 `/etc/pagesai/secrets.env`，`0600`，属主为运行用户），不写进代码、镜像层或日志。
5. 模块 `dataFile`、`uploadsDir`、`attachments/` 放专用目录（示例 `/srv/pagesai/data`），与代码目录分离。
6. 只注入来自受控来源的适配器；审查其网络访问与日志行为。
7. 关闭不需要的功能与模块；`PAGESAI_MODULES` 与实际一致。
8. 备份加密；秘密材料与数据分开存放。
9. 升级前核对版本与迁移；回退必须配合备份。
10. 公开部署前完成：许可证、第三方声明、敏感信息扫描、漏洞披露渠道。

## 6. 报告安全问题

`SECURITY.md` 已建立政策、不变量与支持范围，但接收报告的私有渠道仍为占位。公开发布前：

- 不要在公开 issue 中贴可利用细节、真实用户数据或密钥。
- 通过项目负责人指定的私有渠道报告，附影响范围、复现步骤、版本与建议修复。
- 已知密钥泄露时先轮换再修代码，并检查日志与备份是否同样泄露。
